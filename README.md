# ascii-scenes-and-mascots

A Claude Code skill for glyph/ASCII scenes and pixel mascots (wearables, creatures, poses, emotes).

- Installed for every project at `~/.claude/skills/ascii-scenes-and-mascots/`.
- To vendor it into one repo: copy this folder to `<repo>/.claude/skills/`.
- To move it to another machine: clone this repo into `~/.claude/skills/`.

Tools need Python 3 with Pillow and numpy. Start at SKILL.md.

The bundled JetBrains Mono font is under the SIL Open Font License (tools/JetBrainsMono-OFL.txt).
